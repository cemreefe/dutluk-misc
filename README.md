# dutluk-misc

Misc dutl.uk apps, one folder each.

- `anitkabir/` — showcase + download for the Anıtkabir inscription typeface (Emin Barın's 1952 mausoleum lettering, traced from Metin Akın's digitization poster)
- `fonteditor/` — static glyph editor/tracer; loads font contour JSON and exports edited outlines
- `warp/` — perspective deskew tool; drag 4 corners on an image (paste/drop/URL), live preview, download warped
